## 关于VPS价格的几个常见问题

**VPS一个月多少钱算便宜？**
入门1核1GB档，月付3到5美元就是市场正常低价（Hetzner $3.79、Contabo $4.50 这个水平）；折算到每月1美元以下的地板价，基本只出现在年付促销里，比如 RackNerd 的 $11.29/年。

**RackNerd续费会涨价吗？**
促销年付方案是循环价，到期前续费价格不变。真正要留意的是别让服务过期——过期后重新下单，能不能赶上原价就看当期促销了。

**年付和月付怎么选？**
确定要用满半年以上就选年付，对照前文表格，1核1GB月付阵营要 $3.79 到 $6，年付促销只要 $11.29 一年，差价在一半以上。拿不准的，先买最低档年付试线路和性能，试错成本也就一顿饭钱。

**AWS这些大厂贵一倍，为什么还有人用？**
溢价买的是全球节点、企业级SLA、按秒计费和完整生态。个人项目用不上这些，就没必要付这笔钱；团队有合规和架构要求时，这部分开销才花得其所。
